## Datos de origen / Source data

Precios y ubicaciones de estaciones de servicio: Ministerio para la Transición Ecológica y el Reto
Demográfico (MITECO), API pública de precios de carburantes. Reutilización permitida conforme a las
condiciones de reutilización de la información del sector público
(Ley 37/2007 y Real Decreto 1495/2011).

Station prices and locations come from MITECO's public fuel-price API and are reused under Spain's
public sector information reuse rules (Ley 37/2007, Real Decreto 1495/2011).
